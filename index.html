daisyUI: [class~="not-prose"] * restyles whole subtrees

The button component ships .prose :where(a.btn:not(.btn-link)):not(:where([class~="not-prose"], [class~="not-prose"] *)). In Chrome, that selector makes any class change on any element restyle all of its descendants, even on a page that never uses .prose or .btn.

This page loads daisyui.css from jsDelivr, builds about 1,500 plain elements, then toggles an unused class on <html> and on one <p>, forcing a style recalc each time. It runs three versions of the CSS:

  1. Original: daisyUI as published.
  2. #4888 applied: the :has() fix from #4888, for comparison.
  3. #4888 + .not-prose: [class~="not-prose"] written as .not-prose (same elements, same specificity).
